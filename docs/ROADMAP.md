### 대학 분석 · 강사 정답 키 대조 (보류 — 도입 시기 알림 대상)
강사가 해당 대학의 실제 변화(7개 항목 × 전형)와 TOP 3를 정답 파일로 만들어 두면,
교육생 제출물과 대조해 **놓친 변화 / 잘못 분류한 변화 / TOP 3 일치 여부**를 자동으로 보여준다.
- 스키마 자리: `js/univ-schema.js`의 `answerKey` 주석 위치
- 적절한 도입 시점: 2강 실습을 1회 이상 운영해 교육생 제출 파일이 쌓였을 때,
  또는 2단계(Supabase) 전환 직전 — 서버 전환 후에는 강사 계정에 정답 키를 두는 편이 자연스럽다.
