# Expert Course · 입시컨설팅 진단실

입시 전문가 과정 실습용 **10단계 상담 진단 대시보드**입니다.
학생 사례를 학생정보 → 목표 → 교과·학생부·수능 경쟁력 → 전형별 경쟁력 → 후보 → Risk → 지원전략 → 학생·학부모 설명 순서로 기록하고,
누락 항목과 리스크를 실시간으로 점검합니다. **합격 가능성을 자동 산출하지 않습니다.**

## 현재 단계: 1단계 (정적 호스팅)

| 항목 | 1단계 (현재) | 2단계 (예정) |
|---|---|---|
| 호스팅 | GitHub Pages | GitHub Pages (동일 주소) |
| 로그인 | 없음 | Supabase Auth |
| 저장 | 이 브라우저(localStorage) + JSON 파일 백업 | 계정별 서버 저장 |
| 강사 열람 | 교육생이 백업 파일 제출 | 기수별 조회 |
| 배부 | 같은 링크 공유 | 기수별 배부 링크·인원 한도 |

> 1단계 저장 데이터는 **각자의 브라우저에만** 있습니다. 다른 기기·브라우저에서는 보이지 않으므로 **전체 백업**을 권장합니다.
> 2단계 전환 후에는 전체 백업 파일을 불러와 계정으로 옮길 수 있습니다.

## 구조

```
index.html
css/style.css
js/
  config.js            배포 설정 (저장 방식, 기수 이름, 저장 한도)
  schema.js            10단계 입력 항목·검증 규칙 (1·2단계 공통)
  app.js               화면·진단 로직
  storage/
    index.js           config.storage 값에 따라 저장소 선택
    local.js           1단계: 브라우저 저장
    supabase.js        2단계: 서버 저장 (예정)
docs/supabase-plan.md  2단계 테이블·권한 설계
```

저장 방식을 바꿔도 `app.js`는 그대로 두고 `storage/` 안의 어댑터만 교체합니다.
모든 어댑터는 `init / list / create / update / remove` 다섯 가지 메서드를 같은 모양으로 제공합니다.

## 배포 (GitHub Pages)

Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
몇 분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

## 개인정보 원칙

- 실습에는 가상 사례를 사용합니다.
- **실제 상담 모드**에서는 공용 PC 사용을 피하고, 이름은 이니셜 입력을 권장합니다.
- 학생 데이터(백업 JSON)는 **저장소에 커밋하지 않습니다** (`.gitignore`로 차단).
